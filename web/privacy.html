1. Introduction

Muscle Master (ci-après "l'Application") respecte votre vie privée. Cette politique de confidentialité explique quelles données nous collectons, pourquoi, comment nous les utilisons, et vos droits concernant ces données.

En utilisant Muscle Master, vous acceptez les termes de cette politique de confidentialité.

2. Données Collectées

2.1 Données de Compte

  • Email : Pour créer et gérer votre compte
  • Identifiant utilisateur : ID unique généré automatiquement
  • Nom d'utilisateur : Pseudonyme choisi par vous

2.2 Données d'Entraînement

  • Programmes créés : Exercices, séries, répétitions, charges
  • Historique des séances : Date, durée, exercices effectués
  • Données de progression : Poids, charges maximales (RM), performances

2.3 Données Nutritionnelles

  • Journal alimentaire : Aliments consommés, macros (protéines, glucides, lipides)
  • Objectifs nutritionnels : Calories cibles, répartition des macros

2.4 Données Vidéo et Multimédia

  • Vidéos d'exercices : Enregistrements de vos séances pour analyse de technique
  • Audio : Son enregistré dans les vidéos (pour l'analyse contextuelle)
  • Stockage local : Vidéos stockées uniquement sur VOTRE appareil
  • Contrôle total : Vous pouvez télécharger, partager ou supprimer vos vidéos à tout moment

📹 IMPORTANT : Vidéos d'Exercices

Les vidéos que vous enregistrez pendant vos séances sont stockées UNIQUEMENT sur votre appareil. Muscle Master ne les envoie PAS sur des serveurs externes, sauf si vous les partagez volontairement.

  • ✅ Stockage 100% local sur votre téléphone
  • ✅ Vous contrôlez le partage (réseaux sociaux, analyse IA)
  • ✅ Vous pouvez les supprimer à tout moment
  • ✅ Pas de collecte automatique par Firebase

2.5 Données Techniques

  • Analytics : Pages visitées, durée d'utilisation, fonctionnalités utilisées (via Firebase Analytics)
  • Crash reports : Rapports d'erreurs anonymisés (via Firebase Crashlytics)
  • Informations appareil : Type d'appareil, version OS, langue

⚠️ IMPORTANT : Firebase et Collecte de Données

Muscle Master utilise Firebase (Google) pour le backend. Même si vous n'avez pas de compte, certaines données techniques sont collectées automatiquement :

  • Analytics : Suivi de l'utilisation de l'app
  • Crashlytics : Détection et rapport des bugs
  • Performance Monitoring : Mesure des temps de chargement

Ces collectes sont déclarées dans Google Play Console (Data Safety) et App Store Connect.

3. Finalité de la Collecte

3.1 Fonctionnement de l'Application

  • Créer et gérer votre compte
  • Sauvegarder vos programmes et séances
  • Enregistrer et analyser vos vidéos d'exercices (stockage local uniquement)
  • Suivre votre progression
  • Personnaliser votre expérience

3.2 Amélioration du Service

  • Analyser l'utilisation pour améliorer l'UX
  • Détecter et corriger les bugs
  • Optimiser les performances

3.3 Communication

  • Notifications sur vos séances et objectifs
  • Mises à jour de l'application
  • Support utilisateur

4. Partage des Données

🔒 Muscle Master NE VEND PAS et NE PARTAGE PAS vos données personnelles avec des tiers à des fins commerciales.

4.1 Services Tiers (Firebase/Google)

Vos données sont hébergées sur Firebase (Google Cloud) et soumises à la politique de confidentialité de Google : https://policies.google.com/privacy

4.2 Obligations Légales

Nous pouvons divulguer vos données si la loi l'exige (décision de justice, enquête gouvernementale).

5. Conservation des Données

  • Données de compte : Conservées tant que votre compte existe
  • Données d'entraînement : Conservées tant que votre compte existe
  • Vidéos d'exercices : Stockées uniquement sur VOTRE appareil (pas sur nos serveurs)
  • Analytics : Conservées 14 mois par Firebase (politique Google)
  • Crash reports : Conservés 90 jours

🗑️ Suppression de Compte

Vous pouvez supprimer votre compte à tout moment depuis : Profil → Paramètres → Supprimer mon compte

Cette action supprime définitivement et irréversiblement :

  • Votre compte utilisateur
  • Tous vos programmes
  • Votre historique de séances
  • Votre journal alimentaire
  • Toutes vos données de progression
  • NOTE : Les vidéos enregistrées sur votre appareil restent sur votre téléphone

Si vous vous réinscrivez plus tard, vous repartirez de zéro.

6. Vos Droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

6.1 Droit d'Accès

Vous pouvez demander une copie de toutes les données que nous détenons sur vous.

6.2 Droit de Rectification

Vous pouvez corriger vos informations personnelles directement dans l'app (Profil → Informations personnelles).

6.3 Droit à l'Effacement

Vous pouvez supprimer votre compte et toutes vos données (voir section 5 ci-dessus).

6.4 Droit à la Portabilité

Vous pouvez demander vos données dans un format structuré et lisible par machine.

6.5 Droit d'Opposition

Vous pouvez vous opposer au traitement de vos données à des fins de marketing (bien que Muscle Master ne fasse pas de marketing direct).

7. Sécurité

Nous mettons en œuvre des mesures de sécurité appropriées pour protéger vos données :

  • Chiffrement : Communications sécurisées (HTTPS/TLS)
  • Firebase Security Rules : Contrôle d'accès aux données
  • Authentification : Firebase Authentication avec hashing des mots de passe
  • Backups : Sauvegardes régulières

8. Applications Tierces

Muscle Master peut contenir des liens vers des services tiers (YouTube pour les vidéos d'exercices). Ces services ont leurs propres politiques de confidentialité que nous vous encourageons à consulter.
